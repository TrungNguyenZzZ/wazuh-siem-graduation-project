# Wazuh SIEM – Attack Detection Project

## Mục tiêu
Triển khai hệ thống SIEM dựa trên Wazuh và ELK Stack
để phát hiện và phân tích các kịch bản tấn công mạng phổ biến.

## Nội dung chính
- SSH brute-force detection
- File Integrity Monitoring
- SQL Injection, XSS, LFI detection
- Kibana Dashboard visualization
- Email alert using Watcher
- Machine Learning for alert prioritization
